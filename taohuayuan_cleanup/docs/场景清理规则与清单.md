## 五、保留对象清单（含理由）

- **农田/种植网格/PlotInteractable**：玩法核心，零改动
- **道路碰撞与 RoadBuilder 薄片**：主街/乡间路动线，零改动
- **围栏 FenceSeg（z=15 一排 + 东侧封口）**：院区边界，缺口 x∈[-1.2,1.2] 可通行
- **石头/木箱/野花/草丛/蘑菇/长椅**：PH3 审计后有意布局，已避开道路与主屋
- **商店柜台/木箱/桶**：ShopUmbrella GLB 内部 Decor_*，零碰撞，NPC 兔大妈摊位配套
- **边界林带/界外森林毯/河带延长**：边界软化，有明确设计意图
- **喷泉/石板圆盘/路灯/采集占位/NPC 站位脚垫**：镇区广场与 3.4 玩法预留，纯视觉或玩法标记
- **全部 StaticBody / Door_Blocker / OcclusionFader 遮挡体**：碰撞与遮挡分工，禁删

## 六、通行性回归覆盖（第 42 套件 21 断言）

1. 三档（L0/L1/L2）× 三路（正面/左前/右前）到达门口交互圈
2. 门口区无独立木板/箱子等异物 layer1 碰撞
3. InteractionManager 识别 HouseDoor + F 触发进屋 → HouseInterior
4. 农场/镇区无 6×4 方形 BoxMesh 遗留（清理锁定）
5. 镇区主动线 4 段（店门/广场/北桥/南口）可达
6. 杂货铺门口柜台木箱不阻挡进店

## 七、后续规则（防复发）

- 任何"过渡/占位"地面一律走 `GroundTint.organic_patches`，禁止新增 BoxMesh 方片。
- 门口区域新增装饰必须是零碰撞 Decor，且需在 `test_cleanup_traversal` 的异物碰撞检查下保持为空。
- 清理任何节点前先查明来源（GLB 内部 / 程序化 / 独立摆件 / 碰撞体），按本表分类，禁止按名称批量删除。
