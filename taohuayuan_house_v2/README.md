# 《桃花源物语》第二轮 Blender 测试房屋 — 送审材料

本目录是**独立测试资产**，未接入正式游戏、未替换任何现有建筑。供人工/AI 审查风格与造型是否达标。

## 1. 这轮要做的是什么

游戏是 Godot 4.7.2 的 2.5D 田园生活模拟（正交斜俯视、90° 分段旋转镜头）。
第二轮房屋任务要求：**接近《动物森友会》的温馨卡通生活模拟建筑风格 + 少量中国乡村元素点缀，蓝灰色青瓦两坡屋顶**；不要传统古建筑的斗拱/飞檐/厚重台基。

## 3. 中国元素用量（按要求只取两处）

- ✅ 采用：门前两级石板、小竹篱笆（3 柱 2 横杆）

## 6. 已知问题 / 需要审查时重点看

1. **三角面数 11840 高于建筑预算区间 150~8000**，属"主角级"用量。可把倒角段数 3→2 降约 20%，但是否要降需审查后决定（会影响圆润感）。
2. **瓦层目前是 3 条阶梯式薄板 + 明暗交替**，不是真实瓦片纹理；远看有层次，近看仍是几何拼贴。
3. **未做贴图**，全部为纯色材质（低多边形卡通风格），因此近看略显"塑料感"。
4. 背面虽有窗与木饰条，但装饰密度低于正面，四面对比仍有轻重差。
5. 本目录不含 .blend（体积较大未上传），只上传了 .glb 与截图；.blend 保存在本地私有项目仓库。

## 7. 请审查回答的问题

- 造型与比例是否符合"可爱温馨 + 玩具感"的目标？还有哪里显得笨重或头重脚轻？
- 屋顶的层次表现方式是否足够，还是需要改成真实瓦片排列（会增加面数）？
- 四个方向的立面设计是否均衡？背面需要再加什么？
- 中国元素的两处点缀是否恰当，会不会太少或太刻意？
- 若要进入正式建筑资产生产，这栋房子还需要改哪几处？
