## 二、ENV-2② 伞盖屋顶微调（接线点：`shop_umbrella.py` / `umbrella_roof()` 146–232 行）

### 2.1 数值冲突与自洽口径（必须先讲清）

- 以**现状** rx=2.95 / ry=2.45 再缩 8–10% → rx=2.66–2.71、ry=2.21–2.25，对墙外挑只剩 **0.20–0.29 m**，直接违反 0.38–0.42 m，且屋顶边缘几乎压到檐柱中心（柱中心 ±2.68/±2.18），伞盖读不出来。此路不通。
- 以**外挑 0.38–0.42 m** 反推（墙半宽 2.46/1.96）→ rx=2.84–2.88、ry=2.34–2.38，相对现状只缩 1.4%–3.7%。
- 因此"缩小 8–10%"只能以**最初被否决的大檐口版 3.15/2.65**为基准（文件 149–151 行注释即记录该版）；本次是继 3.15→2.95 之后的第二步收敛，**累计**达到该幅度。
- 取**上界 0.42 m**：檐柱中心 ±2.68/±2.18、柱帽半宽 0.15 → 柱帽外沿 2.83/2.33；rx=2.88/ry=2.38 时盖柱余量 0.05 m（若取 0.40 仅余 0.03 m）。0.42 是同时满足外挑约束与盖柱关系的最优解。

### 2.2 为什么缩小后仍是"伞盖"、不压墙、与 MODEL-1 L1/L2 统一

- **伞盖识别度**：识别来自四个不随尺寸消失的特征——椭圆轮廓、8 波檐缘、10 根放射伞骨、中心顶珠；本轮四项全保留，仅整体收 2.4%/2.9% 与边缘减薄。波纹幅度按同比缩小，褶皱的相对节律不变。
- **不压墙**：屋顶边缘仍在墙外 0.42 m，檐口上表面高度 3.43 m 不变，柱帽/招牌遮挡关系不变；俯视投影面积减小 5.2%，对墙面的覆盖比从 1.178 降到 1.117，正是用户要的"松一口气"。现有顶视图（shop_front_detail / town_shop_neighbors）里盘子几乎糊住整面墙，收这一档即可解决。
- **风格统一**：与已验收 MODEL-1 L1/L2 蓝灰屋顶共用同一 sRGB 反解口径与 albedo，色相/明度完全不动；形状语言仍是圆润低多边（segs=32、smooth=True），未引入尖角或新装饰件。相比风格样张中的珊瑚色样版，正式镇区已是蓝灰家族，本轮不跨家族迁移。
- **自然、不灰盒、不过度**：只削边缘 23.6% 的厚唇，不把屋顶压成薄片；直径 -2.4%/-2.9% 是可感知但不改性格的量级；累计 -8.6%/-10.2% 恰好回到"外挑够用、不抢戏"的已验收区间。

**玩法影响结论：零。** 屋顶、伞骨、顶珠、檐柱均为 Decor 无碰撞件；未改墙体、门窗、招牌、台阶、农田/道路、导航与交互数据；面数不增。
