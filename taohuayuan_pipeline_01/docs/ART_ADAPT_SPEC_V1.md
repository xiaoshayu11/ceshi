# 《桃花源物语》外部素材视觉适配规格 v1

范围：Polyfork Nature & Forest Kit 42 件 + Poly Pizza 8 件（清单见 `../CANDIDATE_LIST.md`）
平台：移动端（Android 优先）· Godot 4.7.2 · 顶点色低模为主
版本：v1.1 · 2026-11-22 · 美术总监 甄塑之
修订：v1.1 吸收 tech-architect 回执——水面 rim 方案、缩放烘网格/等比规则、拼接与石灯笼限量校验规则（第八节两条改「规则已出」），新增「院落圈定标准」。
性质：**适配规格**，不是资产生产单。凡是标「未接线」的条目，落地时按缺失处理。

## 一、视觉基调（全项目唯一出处，后续资产方向包只引用本段）

1. **风格锚点**：像「晴日上午的江南田园水彩画」，不像任何日式庭院、也不像美式林区低多边形包。
2. **色彩与光照**：暖阳 + 低饱和。绿系三档（主绿 / 暗绿 / 嫩绿），土石木在中明度，点缀色总面积 ≤10%。主光从西南上方、高度角 35–40°，暖白直射 + 冷灰蓝环境补。
3. **形状语言**：全项目只用**圆润块面**（倒角 + 球化顶点），禁止尖刺、硬直角、写实碎边。
4. **尺度比例**：玩家 1.65 m；场景道具按真实尺度的 1.0–1.2 倍；动物按真实体高（见第三节）。角色头身比 1:2.5（本 spec 外）。
5. **色彩预算**：主（植被绿）55–60% / 辅（土·石·木）30–35% / 点缀（花色·秋色·水）≤10%。

> 原素材自检结论（`evidence/overview_s0.png`，47 件陈列）：绿系饱和度偏高、色相跨度太宽（黄绿到蓝绿都有）、水面色块过蓝、枫树红黄三色块抢眼、石材两套灰不统一。**这是本次适配的主要工作量来源。**

## 二、全局色板（目标值 + 容差）

所有 hex 为 sRGB。容差以 **HSV 差值**表达（便于 Blender 驱动 / 批脚本执行），不用 ΔE：
`ΔH ≤ 8°`、`ΔS ≤ 0.06`、`ΔV ≤ 0.08`（同类件之间互差），对目标色 `ΔH ≤ 10° / ΔS ≤ 0.08 / ΔV ≤ 0.10`。

| 组 | 语义 | 目标 hex | H/S/V | 允许范围 | 用途 |
|---|---|---|---|---|---|
| 绿·主 | 主植被绿（阔叶树冠、圆灌木、草簇） | `#7AA063` | 97/0.38/0.63 | H 90–110 | 画面绿基线，占比最大 |
| 绿·暗 | 针叶暗绿（松、杉、深林） | `#4A7355` | 136/0.36/0.45 | H 125–150 | 拉开明度层级 |
| 绿·嫩 | 嫩叶嫩草（白桦、蕨、香蒲） | `#A8C577` | 82/0.40/0.77 | H 76–92 | 高光位，不铺大面 |
| 土 | 土路棕（泥路带、裸土） | `#A98A61` | 34/0.43/0.66 | H 28–38 | 所有路面只此一色 |
| 石 | 石 grey（岩石、石板、汀步、井） | `#96A1A4` | 193/0.09/0.64 | H 185–205，S ≤0.12 | 冷偏蓝，全项目只 2 档灰 |
| 石·暗 | 石阴影面 / 深灰石 | `#6E7A7D` | 193/0.12/0.49 | 同上 | 必须与上一条同色相 |
| 木 | 原木色（围栏、桥、桶、长椅、家具） | `#9C7A5B` | 29/0.42/0.61 | H 24–34 | 结构木材 |
| 木·深 | 深木（梁、门框、旧木） | `#7A5A3E` | 27/0.49/0.48 | 同上 | 与木色同色相 |
| 水 | 水面 | `#7FAFB4` | 186/0.29/0.71 | H 180–200 | 禁纯蓝 |
| 点缀·花 | 桃花 / 野花粉 | `#F0B9C4` | 348/0.23/0.94 | H 335–355 | 全画面 ≤3% |

## 三、逐资产处理清单（重染 / 保留）

判断依据：源色与目标色 HSV 差值 + `overview_s0.png` 目视。凡标「重染」的，dev 阶段必须产出 before/after 对比图才算完成。

| 资产 | 处理 | 动作 | 理由 |
|---|---|---|---|
| broadleaf-oak | **保留** | 仅统一 roughness | 树冠绿落在 绿·主 容差内 |
| tall-pine-tree / young-pine | **保留** | 同上 | 暗绿档，明度可撑层级 |
| round-bush | **保留** | 同上 | — |
| birch-tree | 微调 | 叶色 H 向 绿·嫩 收 5°；树皮锁定 `#E6E1D6` | 源叶色偏黄 |
| fern-plant / grass-tuft / cattail-reed | 微调 | 统一到 绿·嫩，V 提 ≤0.05 | 三件互相色差超容差 |
| maple-tree | **重染** | 红黄橙三色块压缩为 秋红+秋橙 两色，饱和度 ×0.75 | 原色饱和度过高，会破 10% 点缀预算 |
| dead-tree | 视场景定 | 枯木本身保灰棕，**不进绿系**；单场景 ≤2 棵 | 与主绿争夺注意力 |

| large-boulder / medium-rock / small-rock / rock-spire | **重染** | 全部归 石 / 石·暗，同色相 | 现有两套灰需合并 |
| stone-well / stone-fire-pit | 微调 | 石材同上；井口木件归 木·深 | — |
| water-blob | **重染** | 改 `#7FAFB4`，roughness 0.15 + 轻微 Fresnel | 原蓝过饱和，是画面最「硬」的一块 |
| lily-pad | 微调 | → 绿·主，V 提 0.03 | 与水面明度混淆 |
| wildflower | 微调 | 花头 → 点缀·花，茎叶 → 绿·嫩 | — |
| toadstool | **重染** | 伞盖降饱和至 S≤0.45，红改暖砖红 | 原红点过于抢眼 |
| log-cabin | 保原色 + 改用途 | 木色归 木 / 木·深；**仅作森林仓库/柴房** | 用户已定：非玩家住宅 |

## 四、材质统一原则

### 4.1 两类件的分野（不许混）

| | 顶点色件（Polyfork 42 件） | 贴图件（Poly Pizza 8 件） |
|---|---|---|
| 着色依据 | 顶点色 × 白 albedo | 贴图 albedo |
| Godot 配置 | `albedo_color = 白`、`vertex_color_use_as_albedo = true`、`vertex_color_is_srgb = true` | 材质保持贴图；`albedo_color` 只做整体校色乘子（≤1 档，不许逐件手调） |
| 改色方式 | **顶点色 HSV 批处理**（Blender：饱和 ×0.85、V ×1.03，再吸附到色板最近档） | **烘进贴图**（一次颜色校正：饱和 −15%、V +5%），禁止运行时改 |
| 贴图尺寸 | 无贴图 | 512×512 足够；禁 2k |
| 材质数量 | **每件 1 个材质**，且全 kit 共 1 个 `M_VertexColor_Nature` | 按类别共 3 个：`M_PP_Animal` / `M_PP_Stone` / `M_PP_Wood` |

> 硬规则：同一资产类别内**禁止顶点色与贴图混用**（树冠顶点色 + 树干贴图 = 风格打架的头号来源）。

### 4.2 PBR 基准（全部资产）

| 参数 | 值 | 说明 |
|---|---|---|
| metallic | **0.0** | 除明确金属道具外一律 0；金属感是「塑料味」来源 |
| roughness（植被 / 木 / 石） | 0.85 ± 0.05 | 柔和需要高粗糙度，不要半光泽 |
| roughness（贴图动物） | 0.80 | 毛皮感，可比植被略低 |
| roughness（水面） | 0.15 + rim 方案 | 唯一低粗糙度件；BaseMaterial3D 无 Fresnel 滑杆，按 `rim_enabled` 实施（tech-architect），gl_compatibility 下待实测，不达预期再转 ≤10 行自定义 shader。水面独立材质，不进 M_VertexColor_Nature |
| specular | **0.25** | Godot 默认 0.5 会给低模加不存在的高光点 |
| 法线 / AO | **不接**，不烘 AO 贴图 | 顶点色件靠明度分层，接 AO 会让暗部发脏 |
| 阴影 | 投影开，双面渲染关 | 单面可见的草/叶需在 Blender 里补双面或加厚，否则灯光下漏底 |
| 顶点色范围 | 硬限 0.11–0.95 | 禁纯黑纯白，避免死黑与过曝 |

### 4.3 归一化（所有件，无例外）

1. 原点移到包围盒 XY 中心、**脚底 y = 0**；前向统一 **-Z**（Godot forward）。
2. 按第三节 / 第五节目标尺寸缩放，**不保留导入原尺寸**（Google Poly 存档件有 77 m、167 m 的）。
3. **缩放优先在 Blender 里 apply 后烘进网格导出**，Godot 侧 Node3D scale 保持 1.0；动物体高表若必须写根节点 scale，**只允许等比缩放**（xyz 同值），非等比 scale 会毁碰撞体与 MultiMesh。动画件（带骨骼的黄牛）缩放必须烘进网格，禁止骨骼 + 节点缩放叠加。
4. 缩放后复检包围盒，偏差 >5% 回报重建。
5. 导出 glTF 二进制 `.glb`，Y-up，+Y 上；单位 m。

## 六、石灯笼：落位与配比

定位：**中国元素点缀物，不是场景骨架**。石灯笼一旦成排、成轴，场景立刻变日式庭院。

| 项 | 规定 |
|---|---|
| 全场上限 | **≤3 件 / 场景**（含所有区块）；单个院落 ≤1 件 |
| 允许的位置类型（仅此三类） | ① 住宅院门内侧或照壁旁（1 件）② 池塘/溪流驳岸边（1 件）③ 上山小径的转角或岔路口（1 件） |
| 与中式木灯笼配比 | 中式木灯笼（lantern-post）: 石灯笼 ≥ **3:1**，读起来必须是「中式为主、石灯点缀」 |
| 校验挂载 | 场景根节点 metadata `asset_budget`（`stone_lantern_max=3` / `stone_lantern_per_courtyard=1` / `wood_lantern_min_ratio=3.0` / `dead_tree_max=2` / `autumn_tree_max=3` / `bonsai_max=1`），由 lint 脚本按 group（如 `prop_stone_lantern`）计数，超限不进性能测试环节。规则由 tech-architect 出（PERF_SPEC 工具链），本表限量值以本节为准 |
| 尺度 | 高 1.8–2.0 m（低于门洞 1.9 m 视觉上压不住正门，故门侧那件放 1.6 m 矮款） |
| 光 | 夜间只做暖白 `#F5E9D2` 小范围点光/自发光，**不做成路灯**；照明仍是木灯笼的事 |
| 摆放姿态 | 禁对称成对、禁沿路等距排列、禁参道式排布 |

**必须同时满足的排他条件**：石灯笼出现的位置 20 m 内，不得同时存在鸟居、枯山水/白砂、樱花+石灯组合、盆景（Bonsai 盆景限 1 件且只放廊下/室内，不进庭院主景）。

### 「院落」圈定标准（lint 分区计数用）

1. 以玩家住宅 / 森林仓库等功能建筑为中心，由**连续围栏或天然边界**（建筑外墙、水岸、围墙）围合的封闭或半封闭区域；
2. 必须含至少 1 个出入口（wooden-fence-gate 或建筑门洞）；
3. 围合周长 ≤ 60 m，超出按两个院落拆分；
4. 场景分区以**目录约定为准**（`courtyard_01/` 之类），Area3D 可作辅助但 lint 只读目录结构——文件结构比运行时节点稳定；院落之外的区域一律不计入院落限额；
5. 院落内建筑体（住宅 / 仓库 / 柴房）自身视为院落中心，不重复计为独立分区。

## 七、禁止事项（违反即打回）

1. **禁止出现第四种绿**。全项目绿色只允许 H 76–150° 三档（主绿/暗绿/嫩绿）；蓝绿、橄榄绿、灰绿、翠绿一律视为不通过。超出容差的树必须重染，不许「这棵也挺好看」。
2. **禁止任何日元器件进主景**：鸟居、石灯笼成排/成对、枯山水白砂、樱花树成群落。石灯笼按第六节限量限位。
3. **禁止秋色树超过 3 棵同屏**；枫树单棵红黄橙总面积不超过该树冠 60%（原素材三色均分必须压缩）。
4. **禁止贴图件原贴图直出**。Poly Pizza 8 件必须过一遍颜色校正（饱和 −15%、V +5%）后再入库。
5. **禁止顶点色与贴图混用于同一资产类别**；禁止一件模型挂 2 个以上材质。
6. **禁止 metallic > 0**、**禁止 specular 用默认 0.5**、**禁止烘 AO 贴图**到低模上。
7. **禁止纯黑纯白**：albedo / 顶点色下限 0.11、上限 0.95。白桦树皮最低不低于 `#E6E1D6` 一档的 0.85 倍。
8. **禁止原尺寸导入**。任何 Google Poly 存档件不经归一化直接进场景，视为未完成（有 77 m 级的原件）。
9. **禁止动物体高各自为政**：同种不同件、或同一场景内同类（家畜组）尺寸差 >10% 即不通过。
10. **禁止石材出现第三种灰**；禁止路面出现第二种土色。
11. **禁止把 log-cabin 当玩家住宅或用它做主景**（用户已定：仅森林仓库/柴房候选）。
